# 논문 정합성 수동 검토 안내

연구 질문에 논문이 얼마나 직접 답하는지 제목·초록으로 판단합니다. 논문의 유명세, 피인용 수, 가설을 지지하는 결과인지는 관련성 등급의 기준이 아닙니다.

## 읽기와 입력 순서

1. 질문별 자료에서 질문과 조건을 확인합니다: [Q01](Q01-papers.md), [Q02](Q02-papers.md), [Q03](Q03-papers.md), [Q04](Q04-papers.md), [Q05](Q05-papers.md), [Q06](Q06-papers.md).
2. 논문에 표시된 `review_id`로 [조건별 평가표](field-reviews.csv)의 행을 찾아 판정합니다.
3. 같은 ID의 [논문별 평가표](paper-reviews.csv)에 전체 등급과 이유를 입력합니다.

두 CSV는 UTF-8 BOM 형식입니다. 셀 안의 초록에는 줄바꿈이 있을 수 있으므로 CSV를 지원하는 스프레드시트로 엽니다. ID를 변경하거나 행을 지우지 않습니다. 순서는 무작위이며 관련성 순서가 아닙니다. 연구 질문이 다르면 같은 논문도 별도로 판정합니다.

질문 조건은 초안입니다. 조건의 해석이나 CORE 지정에 이견이 있으면 `question_structure_feedback`에 기록합니다. 질문에 없는 조건을 논문마다 임의로 추가하지 않습니다. 미지정 필드는 조건별 표에서 제외했습니다.

## 조건별 평가

| label | 기준 |
|---|---|
| MATCH | 질문의 조건을 직접 다루는 근거가 있음 |
| PARTIAL | 대상 일부 또는 상위·인접 개념을 다룸 |
| MISMATCH | 다른 대상·변수 등을 다룬다는 명시적 근거가 있음 |
| UNKNOWN | 제목·초록만으로 확인할 수 없음 |

`evidence_source`에는 `TITLE` 또는 `ABSTRACT`를 입력합니다. `evidence_quote`는 제공된 제목·초록에서 정확히 복사하고 `reason`에 판단 이유를 씁니다. 번역한 문장을 원문 인용으로 넣지 않습니다. UNKNOWN은 인용란을 비워도 되지만 어떤 정보가 부족한지 이유를 적습니다.

초록에 조건이 없다는 것만으로 MISMATCH를 주지 않습니다. 같은 단어가 등장해도 실제 분석 대상이 아니면 MATCH를 주지 않습니다. `relation`은 두 개념이 실제로 어떤 관계로 연구됐는지를 판단합니다. 증가·감소·효과 없음이라는 결과 방향은 정합성 감점 사유가 아닙니다.

초록이 없는 경우 제목으로 확인되는 부분만 판정하고 나머지는 UNKNOWN으로 둡니다. 전문을 읽어야 하는 경우 논문별 표의 `needs_fulltext`에 `YES`를 씁니다. 이번 제목·초록 평가에 전문에서만 얻은 근거를 섞지 않습니다.

## 논문 전체 평가

| overall_relevance_grade | 기준 |
|---|---|
| 3 | 연구 질문에 직접 답함 |
| 2 | 연구 질문의 중요한 부분에 답함 |
| 1 | 배경 또는 인접 근거 |
| 0 | 관련 없음 |

전체 등급은 조건별 점수를 기계적으로 합산하지 말고 사람이 판단합니다. 판단 근거를 `overall_reason`에 씁니다. 정보가 부족해서 전체 등급을 정할 수 없으면 등급은 빈칸으로 두고 `review_status`를 `INSUFFICIENT_INFORMATION`으로 입력합니다. 관련 없음인 0과 구분합니다.

- `review_status`: 미착수 `NOT_REVIEWED`, 전체 등급 판정 완료 `REVIEWED`, 전체 판정 정보 부족 `INSUFFICIENT_INFORMATION`.
- `reviewer_id`: 판정자 식별자. 조건별 표에도 같은 값을 입력합니다.
- `reviewed_at`: ISO 8601 형식의 판정 시각.
- `needs_fulltext`: `YES` 또는 `NO`.
- `rubric_version`: 현재 `0.1` 유지.

정보 부족 판정도 조건별 표는 가능한 범위에서 작성합니다. 독립 검토를 할 때 다른 사람의 판정을 먼저 보지 않고 별도 복사본에 입력합니다.
